Reduce first, then return cumulative credit

registerCreate one owner UUID and replace stale renderer ownership.
openCreate Channel before opening the tab session.
validateCheck session, execution, generation, and exact sequence.
reduceCommit rows and byte accounting synchronously.
ACK through NCoalesce credit for fully reduced batches.
terminal ACKResolve runQuery only after backend settlement.

Release display payloads, never sessions

Completed background rows, columns, notices, and error detail are recoverable display data. Temp state and transactions are not.

Recency changes only on explicit tab/result selection, giving deterministic eviction and tests.

Eligible LRU release

  • Terminal execution
  • Background tab
  • Full display payload
  • Compact tombstone preserved
  • Marked released with byte count and reason

Protected

  • Current visible tab
  • Active execution
  • Session actor and transaction state
  • Status, counts, timing, omission summary
  • No automatic SQL rerun
128 MiB cap

Release eligible terminal display payloads before retaining a new envelope.

No room

Keep only compact counters, drain future rows, and name up to three budget-owning tabs with Switch and Release actions.

User-visible recovery rules

running

Run becomes Stop. Four batches may be in flight; no spinner or pulse.

failed

Rollback remains available. Earlier result sets stay visible.

unknown

Recheck, Rollback, and Close remain. Rollback is not the only recovery path.

released

Status, counts, timing, omission summary, and session state remain. Copy says display details require a rerun.

budget full

Name the tabs retaining bytes and offer direct actions instead of a silent empty result.
