One clear keyboard route

F8 moves keyboard focus to the first enabled query control. A visible outline identifies the focused control. The hint changes when controls have focus, so “Tab” has an explicit meaning.

F6 still switches SQL and results. Tab inside SQL still indents. On a keyboard with media keys, Fn-F8 may be needed. VoiceOver navigation remains available independently; no Control-Option app shortcut is required.

All three error options

  • Visible “Query failed”, error code and full message.
  • A named alert with an explicit assertive live announcement once per failure. No focus theft.
  • A keyboard-accessible message for rereading and copying details.
  • Keep SQL selection and undo. Keep partial script results labelled partial.
