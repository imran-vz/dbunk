The missing parity foundation

The editor currently checks out a pooled SQLx connection per run, calls fetch_all, and returns one result. Session-local state disappears and large output is fully materialized.

Preserve SQLx for table, schema, admin, and legacy engine paths. Add a dedicated PostgreSQL transport without activating the editor.

Scripts, notices, command counts, partial output, and cancellation are flattened away.

Transaction truth is a state machine

idle

Autocommit ready, or manual mode waiting to issue lazy BEGIN.

active

A transaction is open. Commit and Rollback are available regardless of mode intent.

failed

The authoritative probe reports an aborted transaction. Rollback is required.

unknown

Probe failed, state is disabled, or identity is lost. Recheck, Rollback, and Close remain.

  • Manual mode begins lazily before the next execution.
  • Isolation selects the next manual transaction and is disabled in autocommit.
  • Manual to autocommit requires explicit Commit or Rollback.
  • Raw transaction SQL is reconciled through PID + backend-start identity.
  • The post-execution probe is authoritative; mode rules are defaults only.
  • One dedicated observer per Connection batches PID + backend-start probes.
  • Active, failed, or unknown tab close asks before rollback and close.
  • Socket close is the final rollback guarantee.

Risks and hard stops

STOP

Behavior parity

Stop if the shared connect spec cannot preserve resolved routing, permissive TLS Prefer server-refusal fallback, the full handshake deadline, and every currently effective driver option.

STOP

TLS evidence

Require both plaintext server-refusal fallback and a successful encrypted connection to the isolated self-signed fixture.

STOP

Delivery contract

Stop if a typed Channel cannot pair ordered batches and execution terminals with exact acknowledgements.

STOP

Transaction truth

Stop if the dedicated observer cannot reconcile idle, active, and aborted state without acquiring the five-slot SQLx pool.

STOP

Large value

Stop if the 16 MiB single-cell characterization crashes, hangs, or loses the session. Never claim a transient frame byte bound.

REVIEW

Cancellation race

A cancel request is not proof of cancellation. The terminal server response decides the outcome.

STOP

Background safety

A minimized or occluded macOS window must not roll back because its JavaScript timers were throttled.

REVIEW

Observer cost

Measure the extra roundtrip and coalescing behavior. Do not trade transaction truth for an unverified latency shortcut.

REVIEW

Dark handoff

Plan 001 records a completion SHA. Plan 002 owns all frontend changes and activation.
