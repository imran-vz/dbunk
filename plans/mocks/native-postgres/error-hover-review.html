Behavior to preserve

SituationExpected behavior
Hover or keyboardRead the same message and code. Escape dismisses the hover. It stays readable while the pointer moves into it; focus and SQL selection stay intact.
Run a selectionMap the server position back through the exact executed range. A repeated statement elsewhere in the buffer must not receive the underline.
UnicodeTranslate PostgreSQL character positions to editor offsets without splitting emoji or combining text.
Edit after executionRemove the old underline and hover. If the query fails after the buffer changed, keep the execution error above results without attaching it to unrelated current text.
No usable positionShow the error above results. Do not invent a problematic segment or line number.
Resize or scrollThe hover follows the actual shaped text range, stays in the viewport and does not change the verified editor geometry.
New run or reconnectClear obsolete diagnostics. Old-session or old-execution errors cannot mark current SQL.
VoiceOverAnnounce the terminal error once. Make its details reachable without hover, preserve editor focus and keep ordinary row updates quiet.

PostgreSQL supplies a position, not always a whole range. Underline the containing SQL token where it can be identified safely; otherwise use the reported character or end-of-input location.
